# Career Launchpad AI Tasks

Weekly tasks for the Career Launchpad AI program. Each week's notebook sits in its own folder together with the datasets it uses, so notebooks run as-is from inside their folder.

| Week | Topic | Contents |
|------|-------|----------|
| [week-1](week-1) | Data cleaning and preprocessing | `Task 1.ipynb`, `Automobile.csv` |
| [week-2](week-2) | EDA, feature engineering and baseline modeling | `Steel Industry Energy Consumption.ipynb`, `Steel_industry_data.csv`, `steel_data_engineered.csv` |
| [week-3](week-3) | Clustering models and association rules | `Week 3 Clustering models and Association Rule.ipynb`, `Mall_Customers.csv`, Tesco groceries data and outputs, `tesco_transaction_encoder.py` |
